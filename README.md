英语训练桌面应用。把一套卷子拆成一座星港，做题、背词、看解析，全部在本地完成。

## 它是什么

一个只管做题的工具。打开是星空一样的星港列表，每一颗星是一套训练包；
点进去是「左边材料、右边题目」的双栏，做完当场出分，每道题都能摊开看解析。

完全离线，完全免费：没有账号、没有内购、没有功能锁、不收集任何个人信息。

## 能做什么

**星港训练**
随包 14 个原创训练包、198 道题，分在四座星港：四级（5 包 68 题）、
六级（3 包 30 题）、考研（3 包 40 题）、精练苍穹（3 卷 60 题）。

**导入自己的材料**
把试卷文字粘贴进来，或者选一个文件夹批量导入 —— 程序会拆出材料、题目、答案和解析，
当场生成一套能做的卷子。PDF、Word 里复制出来的文字都能用。

**背词与默写**
36 个自建词条、6 个主题。闪卡翻面看释义，默写练拼写，进度按间隔重复安排复习。

**听力训练**
三档音源：自备录音、随包真人录音、系统语音实时朗读。对话类材料默认盲听，
先听再看原文。录音支持拖动、变速。

**逐题解析**
对错、答案、原文出处、讲解，都在题目下方折叠展开。

## 关于内容

**程序只提供工具，不内置任何第三方试题。**

随包的内容全部原创：训练包里的题目与解析、词库里的词条、听力专项的题目，
都是本项目自己写的。听力用的对话录音属于公有领域素材，可以随程序分发。

你自己导入的材料，其著作权归原权利人 —— 请只导入你合法取得的材料，仅限个人学习使用。
本项目不提供、不代为分发任何第三方试题。

## 数据

进度、错题、笔记都存在程序目录旁边的 `data/` 文件夹里，几个 JSON 文件。
整份拷走就是迁移，换台机器接着练。没有账号，也没有云端同步这一环。
